# 05. Restricciones — SIJASS
| ID | Restricción | Efecto |
|---|---|---|
| RC01 | Señal intermitente o inexistente | Persistencia y procesamiento local |
| RC02 | Equipos móviles de bajos recursos | Optimización del modelo |
| RC03 | Recursos económicos limitados | Monolito modular y software abierto |
| RC04 | Desarrollo académico con equipo pequeño | Despliegue y diagnóstico sencillos |
| RC05 | Datos de familias y pagos personales | Acceso mínimo, cifrado y respaldo |
| RC06 | Fotografías bajo luz variable | Guía de captura y detección de calidad |
| RC07 | Inferencia local preferente | Modelo ONNX cacheable |
| RC08 | Despliegue sin tienda | PWA instalable |
| RC09 | Operaciones concurrentes y reintentos | UUID e idempotencia |
| RC10 | Múltiples roles JASS | RBAC |
| RC11 | Marco regulatorio de agua potable peruano | Parámetros administrables y validación normativa |
| RC12 | Necesidad de evidencia trazable | Auditoría de mediciones y modelo |

No se presume cumplimiento normativo solamente por usar un rango de referencia; se requiere contrastar la norma aplicable y protocolos oficiales vigentes.
