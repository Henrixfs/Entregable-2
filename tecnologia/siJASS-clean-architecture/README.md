# Prototipo TypeScript — SIJASS
Organización Clean Architecture: `dominio` (entidad y puertos), `aplicacion` (caso de uso), `infraestructura` (repositorios en memoria), `pruebas` (test unitarios). No contiene un predictor DPD, servicios HTTP, credenciales, despliegue ni cálculo automático de dosificación.

```bash
npm install
npm test
npm run build
```
Requiere Node.js 20+ y npm; los comandos se ejecutan desde esta carpeta.
